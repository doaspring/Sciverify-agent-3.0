# SciVerify Agent — 公网体验版

面向科研实验的**统计设计审查与可信结论验证智能体**（兴智杯·方向三参赛作品演示）。

书生 Intern-S2 负责自然语言任务理解与白名单统计工具选择；本地确定性代码
（Pandas/SciPy）负责全部数值计算；六条设计风险规则在数据不可靠时**阻断**
不当推断（例如把 24 行技术重复误当 24 个独立样本）。

## 体验指引（无需任何账号）

1. 点击左侧「一键载入合成演示数据」的任一案例（均为固定种子合成数据）：
   - **案例A 正常**：两独立组各 6 批次 → 确认设计 → 运行 → Welch 检验+报告
   - **案例B 陷阱**：4 批次 × 3 技术重复 = 24 行 → 未确认时被 **BLOCK**；
     确认技术重复并授权按单位聚合后，以 8 个独立单位重新分析
   - **案例C 配对陷阱**：处理前后对比但缺 pair_id → **BLOCK** 并说明原因
2. 在「③ 研究设计确认」回答实验单位含义（系统绝不默认"一行=一个独立样本"）
3. 「④ 设计风险审查」→「④½ 智能体执行」→「⑤ 统计结果」→「⑥ 下载报告与复现包」
